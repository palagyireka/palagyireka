## About me

I'm a full-stack developer with experience delivering software for **public services, cultural institutions, and independent clients**. My work spans API design, relational databases, frontend development, deployment, and the sometimes messy data work that connects them.

I enjoy owning a feature end-to-end, but I'm equally motivated by working alongside engineers I can learn from. I'm particularly interested in growing further in **backend development**, building maintainable systems, and understanding the architectural decisions behind them.

Outside of software, I study ceramics — another discipline where technical precision and creative problem-solving meet.
